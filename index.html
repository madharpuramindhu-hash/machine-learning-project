How the prediction works

The system uses a logistic regression model, a standard machine learning classifier. Each mark is multiplied by a weight, the results are added up, and a sigmoid function turns the total into a probability between 0 and 1. The weights in script.js are set by hand for this demo; with real class data you would train them.
